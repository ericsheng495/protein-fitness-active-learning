Contents of the data folder:

README.txt: file descriptions
sequence.fasta: the sequence of the wild-type protein
train.csv: mutants with known DMS_score
test.csv: file containing all possible mutants other than the training mutants
query_round_1.txt: mutants already sent for round 1
query_round_2.txt: mutants already sent for round 2
query_round_3.txt: mutants already sent for round 3
query_round_1_results.csv: measured labels from round 1
query_round_2_results.csv: measured labels from round 2
query_round_3_results.csv: measured labels from round 3
